# A Chapter I'll Always Remember 🌙

Upload these files to the same GitHub Pages repository:

- `index.html`
- `style.css`
- `script.js`
- `Mengejar Mimpi.mp3` ← upload your own MP3 file

The website works without external images. The clouds, moon, stars and floating hearts are made with HTML/CSS/JavaScript.

## Adding photos
You can later add your own JPG/PNG photos and replace each `.photo-placeholder` in `index.html` with an `<img src="nama-foto.jpg" alt="...">`.

## GitHub Pages
1. Open your repository.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for the Pages URL to appear.

Note: the MP3 file is not included in this package; use a music file you have the right to upload.
