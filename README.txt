CARA UPLOAD:
1. Ekstrak ZIP ini.
2. Masuk ke repository GitHub kamu.
3. Upload index.html, style.css, dan script.js.
4. Upload file musik dengan nama persis: Mengejar Mimpi.mp3
5. Semua file harus berada di folder utama repository.
6. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
